# cronai-labs/homebrew-tap

Homebrew tap for [CronAI Labs](https://github.com/cronai-labs) tools.

## Install

```bash
brew install cronai-labs/tap/schriftsatz
```

**Use the fully-qualified name.** Homebrew 6.0 introduced tap trust: after a bare
`brew tap cronai-labs/tap`, an unqualified `brew install schriftsatz` is refused —

```
Error: Refusing to load formula cronai-labs/tap/schriftsatz from untrusted tap
```

— while the fully-qualified form above installs without further steps. Most tutorials still
show the two-step `brew tap` + `brew install` pair, which no longer works.

## Contents

| Cask | What it is |
|---|---|
| `schriftsatz` | Markdown to print-ready PDF via pandoc and XeLaTeX, with a text layer that survives extraction |

Casks here are **generated by [goreleaser](https://goreleaser.com) on release** and pushed
from the source repository. Do not edit them by hand — the next release overwrites them.

`schriftsatz` is a cask rather than a formula because it ships a pre-compiled binary; formulae
that install pre-built binaries were a workaround from before Linuxbrew supported casks, and
goreleaser deprecated that shape in v2.10.

## Dependencies

The cask declares `pandoc`, `texlive` and `poppler`, all of which are homebrew-core formulae —
so the TeX distribution is installed for you rather than described in a README. `uv` is
optional and enables the second-extractor cross-check in `schriftsatz verify`.
